# Bloxyman Studio

A simple 2D building and scripting studio made with Python (Tkinter).

Build blocks, spawn a stickman character, apply gravity, and experiment with scripting features.

---

## 🚀 Features

- 🧱 Left Click = Place Block  
- 🗑 Right Click = Delete Block  
- 🧍 Add Player (Stickman)  
- 🚧 Collision system  
- 🌍 Gravity system  
- ▶ Run All = Start physics  
- ⏹ Stop = Reset player  
- 🎨 Color chooser  
- 📜 Script system  
- 💾 Save / Open project files  

---

## 🎮 Controls

| Key | Action |
|------|--------|
| A | Move Left |
| D | Move Right |
| SPACE | Jump |

---

## 📥 Download

Download the latest version from the **Releases** section or the website download page.

After downloading:

1. Extract the ZIP file.
2. Open the extracted folder.
3. Run `bloxyman_studio.exe`.

If Windows shows a security warning:
- Click **More Info**
- Click **Run Anyway**
